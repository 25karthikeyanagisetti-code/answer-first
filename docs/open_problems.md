Unfinished threads from earlier runs. Each daily run spends Phase 8 of
[deep_run.md](deep_run.md) pushing the **top** item forward. Add progress under
the item with a date. Move settled items to `## Settled`.

## Open

1. **Odd n in 2ⁿ − 2n − 1 = x²** (from [2026](../discoveries/2026-10-05_2026-mersenne-square/)).
   Even n is proven to have no solutions; odd n is sieved only to 2·10⁶. Try
   extending the sieve, a lower-bound argument like Ramanujan–Nagell, or a
   reduction to an elliptic or Thue equation.
2. **Centered cube ∩ 12-gonal numbers** (from [1729](../discoveries/2026-10-05_1729-non-taxicab/)).
   Found {1, 1729, 6034609, 3391605945, 5227631785}. The curve has genus 1, so
   the set should be finite. Find the curve explicitly and prove that the list is complete.
3. **Primorial-area hypotenuse sequence** 5, 13, 29, 137, 569, 1597, 10957, 51781
   (from [137](../discoveries/2026-10-15_137-primorial-triangle/)). Extend
   past k = 9, look at its growth, and check whether it is ready to submit to OEIS.
4. **Which primorials are exactly the area of a PPT?** Known so far: 3# (5), 5# (13), 7# (29), 11# (221), 17# (1597), with the hypotenuse in brackets. Is 13# one? Characterize them.
